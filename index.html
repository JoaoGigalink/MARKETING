Como usar o ClickUp com a esteira de mídia

A automação cria o conceito, os textos e as imagens de uma campanha sozinha. Sua parte é revisar cada etapa e dizer "tá bom" ou "ajusta isso" — este guia mostra exatamente onde clicar e o que escrever em cada uma.

Você não precisa escrever nada de campanha do zero. Você preenche um formulário curto, e a partir daí a automação vai gerando cada parte (conceito, textos, imagens) e avisando você a cada etapa. Sua única função é aprovar ou pedir ajuste.

Existem só duas formas de responder, dependendo da etapa:

📄 no Google Doc 🏷️ no próprio ClickUp (tag + comentário)

Quando for a etapa de tag no ClickUp, as cores abaixo são exatamente as mesmas que você vai ver lá — procure por elas:

aprovado essa é a tag pra dizer que está bom reprovado essa é a tag pra pedir ajuste
01

Preencher o formulário de briefing

status inicial: Não iniciado
🏷️ preencha o formulário do ClickUp

Tudo começa neste formulário: app.clickup.com/.../v/fm/2ky5bpr8-14373

  1. Abra o link e responda o formulário — nome da campanha, objetivo, público, o que não pode faltar. É só isso, nada de escrever textos de campanha.
  2. Envie o formulário. Isso cria a task automaticamente na lista — você não precisa criar a task na mão.
  3. Abra a task recém-criada e, no topo, troque o status manualmente para Briefing Recebido. É esse clique que liga a automação.

Daqui pra frente, a maior parte dos avanços de etapa acontece sozinha — a task só volta a precisar de você quando houver algo pra revisar.

02

Revisar o conceito

a task vai aparecer em: Validar Conceito
📄 responda no Google Doc

A automação comenta na task com um link pro Google Doc. Abra o link — lá está a big idea, a promessa, o tom da campanha e o raciocínio por trás.

No fim da seção ## CONCEITO tem uma linha Status: PENDENTE. É nela que você decide:

Gostou
Troque PENDENTE por APROVADO. A automação segue pra próxima etapa sozinha.
Precisa mudar
Troque por REPROVADO e escreva o motivo na linha Motivo logo abaixo. A automação refaz o conceito com base no que você escreveu.
03

Revisar a estrutura da campanha

a task vai aparecer em: Validando Estrutura
📄 responda no mesmo Google Doc

No mesmo documento, agora tem uma seção ## ESTRUTURA — a lista de peças que vão ser criadas (quais posts, quais formatos, pra qual canal) e uma apresentação visual do plano completo.

Mesmo mecanismo do conceito: ache o Status: PENDENTE dessa seção e troque por APROVADO ou REPROVADO (com o motivo, se for o caso).

04

Revisar os textos (copy)

a task vai aparecer em: Validar Copy
📄 responda no Doc de textos

Chega um novo link, agora de um documento só com os textos — legenda de post, roteiro de vídeo, etc. Cada texto tem sua própria seção ## COPY: <nome da peça>, cada uma com seu próprio Status: PENDENTE.

Revise cada seção separadamente — dá pra aprovar um texto e reprovar outro na mesma passada.

05

Revisar o mockup

a task vai aparecer em: Validar Mockup
📄 responda no Google Doc

Antes de gerar todas as imagens finais, a automação gera uma imagem de prova de conceito — o mockup — e cola ela dentro do documento, na seção ## MOCKUP.

Serve pra você confirmar o estilo visual antes de gastar tempo gerando o resto. Mesmo mecanismo: Status: PENDENTE → APROVADO ou REPROVADO com motivo.

06

Revisar as imagens e áudios finais

a task vai aparecer em: Validar Derivações
🏷️ aqui muda — responda direto no ClickUp

Essa é a única etapa que não usa o Google Doc. Cada imagem ou áudio gerado é anexado direto na task, com um comentário assim:

## gestor_ti_confiante: post estatico (1080x1080) Proxima acao: para aprovar, adicione a tag `aprovado` e comente `APROVADO [gestor_ti_confiante]`. Para pedir ajuste, adicione a tag `reprovado` e comente `REPROVADO [gestor_ti_confiante]`: <descreva o que precisa mudar>

O texto entre [ ] muda pra cada peça — copie exatamente o que está escrito ali, letra por letra, não invente um nome novo.

  1. Olhe a imagem/áudio anexado no comentário.
  2. Decida: aprova ou pede ajuste.
  3. Adicione a tag certa na task — aprovado ou reprovado — procure pelo ícone de etiqueta no topo da task. É a mesma cor que você vê aqui.
  4. Escreva o comentário no formato exato mostrado acima, com o identificador daquela peça.
aprovadoPeça boa
APROVADO [gestor_ti_confiante]
reprovadoPeça precisa de ajuste
REPROVADO [gestor_ti_confiante]: troca o fundo pra azul escuro

Se a task tiver mais de uma peça (ex. um carrossel com vários slides), repita esse processo pra cada uma — cada peça tem seu próprio identificador e seu próprio comentário de anúncio.

✓

Pronto pra publicar

a task termina em: Publicado

Quando todas as peças de uma task estiverem aprovadas, a automação encerra o ciclo e a campanha está pronta pra sair do papel — imagens, áudios e textos, todos já revisados por você.
